# Structured Notes（結構型商品）

## 定義

結合固定收益工具與選擇權的金融商品，收益隨標的資產表現而變動，通常不保本、風險等級高。常見型態包括 Autocallable Note（可提前出場）與 Memory Coupon Equity-Linked Note（記憶式配息：某期未達配息門檻時，之後達標的期別可補發先前未配的利息）。
