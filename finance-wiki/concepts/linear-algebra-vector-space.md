# Linear Algebra — Vector Space（線性代數：向量空間）

## 定義

向量空間、子空間、線性獨立、生成集（span）、基底與維度、秩（rank）、線性變換（含 Image／Kernel、變換矩陣、基底座標變換）等線性代數核心理論。是財金領域矩陣運算——因子模型、投資組合最佳化、主成分分析（PCA）——的共同數學基礎，但本身是抽象數學理論，不涉及財金應用。
