# Prompt Injection（提示注入攻擊與防禦）

## 定義

攻擊者透過刻意設計的輸入文字，誘導 LLM 偏離原定任務、洩漏系統提示或輸出違禁內容。常見防禦手法包括：角色鎖定（明確宣告唯一任務並禁止更換角色）、禁詞規則（含大小寫/空格變體）、拒絕話術固定化、權威宣稱免疫（拒絕「我是系統管理員」之類的話術）、輸出前正規化檢查（移除零寬字元、標點、大小寫、全形轉半形後再比對違禁字串，防禦同形字/零寬字元繞過攻擊）。即使規則寫得詳盡，特定攻擊手法（如偽裝系統層級訊息的格式注入）仍可能持續得手——防禦是不對稱賽局，攻擊者只需找到一個漏洞。
