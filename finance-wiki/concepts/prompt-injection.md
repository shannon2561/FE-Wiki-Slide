# Prompt Injection（提示注入攻擊與防禦）

## 定義

攻擊者以刻意設計的輸入文字，誘導 LLM 偏離原定任務、洩漏系統提示或輸出違禁內容。常見防禦方式包括：鎖定角色（宣告唯一任務並禁止更換角色）、禁詞規則（含大小寫與空格變體）、固定拒絕話術、不採信權威宣稱（例如自稱系統管理員），以及輸出前的正規化檢查（移除零寬字元與標點、統一大小寫、全形轉半形後再比對違禁字串，防範同形字與零寬字元的繞過）。即使規則寫得完整，部分攻擊手法（如偽裝成系統層級訊息的格式注入）仍可能成功，因攻擊者只需找到一個漏洞，防守方則須擋下所有攻擊。
