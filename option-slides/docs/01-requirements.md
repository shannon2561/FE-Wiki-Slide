# 需求確認紀錄（先討論、後生成）

**日期**：2026-11-23
**目的**：用 LLM Wiki 當唯一知識來源，產生一份教學型 HTML 簡報

## 討論後的共識

| 項目 | 決定 | 理由 |
|---|---|---|
| Wiki 基底 | `生成式AI\wiki`（主 wiki 的作業副本），沿用原本的 CLAUDE.md 規則 | 規則已經寫好，不動主 wiki |
| Ingest 範圍 | 四上財工講義 01、02、03、06、07，每份講義各建一頁 source | 這五份還沒 ingest 過；剛好串成「選擇權為什麼能定價」的主線 |
| 簡報主題 | 選擇權怎麼定價？給外行人的 Black-Scholes 入門 | 跟五份講義的主線一致 |
| 讀者 | 外行人，沒有微積分、機率論基礎 | 讀者越外行，越需要流程檢查 |
| 使用方式 | 讀者自己點開閱讀，沒有人上台講解 | 每一頁都要能獨立看懂 |
| 長度 | 主線 12–15 頁，約 10–15 分鐘讀完 | 五份講義都要出現，前面還要留頁數講白話基礎 |
| 公式 | 主線放公式，並用白話逐項解釋；推導放附錄頁，主線用連結點進去 | 外行人不會卡在數學，想深入的人也找得到 |

## 由共識推出的檢查條件（之後逐頁 loop 會用到）

1. 每頁的內容都要能對回某個 Wiki 頁面（不靠 AI 自己補）
2. 術語第一次出現時，同一頁或前面的頁面要有白話定義
3. 不靠口頭說明，這一頁要看得懂
4. 公式的每個符號都要有白話解釋；推導不放主線
