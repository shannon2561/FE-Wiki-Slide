## 討論後的共識

| 項目 | 決定 | 理由 |
|---|---|---|
| Wiki 基底 | `生成式AI\finance-wiki`（主 wiki 篩選後的副本），沿用原本的 CLAUDE.md 規則 | 規則已完整，主 wiki 不受影響 |
| Ingest 範圍 | 四上財工講義 01、02、03、06、07，每份講義建一頁 source | 五份講義尚未 ingest，且依序構成「選擇權如何定價」的主線 |
| 簡報主題 | 選擇權怎麼定價？給初學者的 Black-Scholes 入門 | 與五份講義的主線一致 |
| 讀者 | 沒有財金、微積分與機率基礎的初學者 | 讀者越缺乏基礎，越需要流程中的檢查 |
| 使用方式 | 讀者自行閱讀，無人上台講解 | 每頁須能獨立看懂 |
| 長度 | 主線 12–15 頁，約 10–15 分鐘讀完 | 五份講義皆須出現，前面另須保留頁數說明基礎概念 |
| 公式 | 主線放公式並逐項以白話解釋；推導放附錄，主線以連結進入 | 初學者不會卡在數學，想深入者仍可查閱 |

## 由共識推出的檢查條件（逐頁檢查使用）

1. 每頁內容皆可對應至 Wiki 頁面。
2. 術語首次出現時，同頁或前頁已有白話定義。
3. 不靠口頭說明，單頁即可看懂。
4. 公式的每個符號皆有白話解釋；推導不放主線。
